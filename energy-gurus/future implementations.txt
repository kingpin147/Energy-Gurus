# Energy Gurus — Functional Improvement Plan

A comprehensive audit of the platform's current capabilities and a prioritized roadmap for high-impact functional improvements.

---

## Current System Snapshot

The platform is a multi-role solar industry directory with:
- **Public**: Homepage, EPC/Brand profiles, Podcasts, Live QA, Resources
- **Roles**: `super-admin`, `admin`, `epc`, `brand`
- **Infra**: Next.js 16, Drizzle ORM + Neon, Clerk Auth, Redis caching, PostHog analytics, UploadThing, Upstash rate limiting


### 1.3 Search on EPC & Brand Directory Pages 🔍
**Problem**: The `/epcs` and `/brands` listing pages have no search or filter. Users must scroll through all results.

**Solution**: Add a URL-param based search (`?q=`) that filters by company name, city, or sector server-side using Drizzle `ilike`.

**Files to change:**
- `src/app/[locale]/(public)/epcs/page.tsx` — add `searchParams.q` filter
- `src/app/[locale]/(public)/brands/page.tsx` — same pattern
- Add a `<SearchInput>` client component that updates the URL on change

---

### 1.4 Profile Completeness Score 📊
**Problem**: EPC/Brand users don't know if their profile is complete. Incomplete profiles reduce directory quality.

**Solution**: Show a "Profile Completeness" progress bar in the EPC/Brand dashboard (e.g., 70% — Missing: Logo, About, Social Links).

**Files to change:**
- `src/app/[locale]/dashboard/epc/page.tsx` — add completeness calculation
- `src/app/[locale]/dashboard/brand/page.tsx` — same

---


### 2.2 Verified Badge System ✅
**Problem**: `isVerified` exists on both `epcInstallers` and `brands` tables but there is no admin UI to set it, and no visual indicator on the directory listing cards.

**Solution**: 
- Admin toggle in Manage Brands/Users pages to set `isVerified`
- Show a green "Verified" shield badge on EPC/Brand listing cards and profile headers

**Files to change:**
- `src/app/[locale]/dashboard/brands/page.tsx` — add verify toggle button
- `src/app/[locale]/(public)/epcs/page.tsx` — show badge on cards
- `src/app/[locale]/(public)/brands/page.tsx` — same


### 2.4 Homepage Live Stats Counter 📈
**Problem**: The homepage has static trust indicators. Real stats would build more credibility.

**Solution**: Show live counts (e.g., "**42** Verified Installers · **8** Solar Brands · **120+** Reviews") pulled from the DB and cached.

**Files to change:**
- `src/app/[locale]/(public)/page.tsx` — add stat query to `getHomepageData()`
- Add a `<StatsBanner>` component between the hero and podcast sections

---

## Priority 3 — Admin Power Features

### 3.1 PostHog Analytics Dashboard — Per-Entity Drilldown 📉
**Problem**: The analytics page shows aggregate platform stats. Admins cannot drill into individual EPC or Brand performance.

**Solution**: Add a "Top Performers" table in the admin analytics dashboard using the existing `getPostHogTable()` function which already returns per-entity data.

**Files to change:**
- `src/app/[locale]/dashboard/analytics/page.tsx` — render the PostHog HogQL table
- Add tabs: "Overview" | "EPC Rankings" | "Brand Rankings"

---

### 3.2 Invitation System — Bulk Invite & Revoke 📩
**Problem**: Currently admins can invite one user at a time. No bulk invite or revoke exists.

**Solution**: CSV upload for bulk invitations, plus a "Revoke Access" button in the Users table.

**Files to change:**
- `src/app/[locale]/dashboard/users/page.tsx` — add CSV upload + revoke button
- `src/lib/actions/invitations.ts` — add `revokeInvitation()` and `bulkInvite()` actions

---

### 3.3 Dashboard Reports Export 📄
**Problem**: The `/dashboard/reports` page exists but likely has limited export functionality.

**Solution**: Add CSV export for inquiries, users, and reviews using a simple server-side streaming response.

**New files:**
- `src/app/[locale]/api/export/inquiries/route.ts`
- `src/app/[locale]/api/export/users/route.ts`

---

## Priority 4 — Trust & SEO

### 4.1 Structured Data (JSON-LD) for EPC & Brand Pages 🔎
**Problem**: EPC and Brand profile pages have no structured data, limiting search engine rich results.

**Solution**: Add `LocalBusiness` JSON-LD to EPC pages and `Organization` JSON-LD to Brand pages.

**Files to change:**
- `src/app/[locale]/(public)/epcs/[id]/page.tsx`
- `src/app/[locale]/(public)/brands/[id]/page.tsx`

---

### 4.2 Sitemap Generation 🗺️
**Problem**: No dynamic sitemap exists. Google cannot efficiently discover individual EPC/Brand profile pages.

**Solution**: Generate a dynamic sitemap from the database.

**New file:**
- `src/app/sitemap.ts` — returns all EPC/Brand profile URLs
